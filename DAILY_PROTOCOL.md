# 60-Minute Protocol

## 0–10 min — Whiteboard
Write the central equation, tensor shapes, assumptions, and expected invariants.

## 10–40 min — Implementation
Work from the starter file. No copied implementation before your first attempt.

## 40–50 min — Verification
Add tests for shapes, numerical agreement, gradients, stability, and at least one failure case.

## 50–60 min — Research note
Question → Hypothesis → Experiment/derivation → Result → Interpretation → Limitations → Next experiment.

## Before pushing
- Remove credentials and all employer/internal material.
- Run `pytest -q`.
- Inspect `git diff --cached`.
- Commit one coherent unit.
